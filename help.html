Help & Guide

1. Add a customer

Go to Customers → Add customer. Enter a name and, optionally, a phone number and delivery address.

2. Create an order

Go to Orders → New order. Choose a customer, add one or more products/services with quantities and prices, and set discount or delivery fee if needed. Save the order.

3. Update delivery status

Open an order and choose Pending, Packed, Shipped, Delivered or Cancelled. These labels are manually recorded; there is no live tracking integration.

4. Record payments

Open an order and choose Record payment. You can save multiple partial payments. The amount due updates automatically. To cancel an order with payments already recorded, resolve/refund those payments first and remove the entries.

5. Reports and backup

Reports show non-cancelled order value, received payments and outstanding balances. Settings lets you export JSON backup and CSV reports. Use Restore JSON backup to replace all current records with a saved backup.

6. Print order slip

Open an order and select Print slip in a regular browser. Native Android WebView may require a Java PrintManager bridge before the print feature works.

7. Android WebView notes

Publish on GitHub Pages over HTTPS. Enable JavaScript and DOM storage in WebView. File chooser is needed for JSON restore; blob-based CSV/JSON downloads and browser printing may require extra native Java integration. Test each function on your device before release.

8. Missing records?

Do not clear browser/app data or uninstall before exporting a backup. Local data belongs to the browser/WebView origin and is not automatically synchronized between devices.
